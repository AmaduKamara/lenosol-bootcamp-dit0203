Software Engineering Curriculum

Industry-vetted modules engineered to take you from foundational syntax to full-stack cloud deployment.

Phase 01: Web Foundations & Version Control

Semantic HTML5 & Modern CSS3

Weeks 1–2

Master Flexbox, CSS Grid, responsive media queries, and accessible component design from UI/UX wireframes.

Git Branching & GitHub Collaboration

Week 3

Feature branch workflows, pull requests, code reviews, resolving merge conflicts, and open-source etiquette.

Phase 02: JavaScript & Modern Frontend

ES6+ JavaScript & DOM Architecture

Weeks 4–6

Asynchronous programming, Fetch API, closures, modular JavaScript, and interactive browser applications.

React & Next.js Applications

Weeks 7–10

Component lifecycles, hooks, client-side routing, state management, and Tailwind CSS integration.

Phase 03: Backend Systems & Capstone

Node.js, Express & PostgreSQL

Weeks 11–13

Building secure REST APIs, JWT authentication, relational database modeling, and Prisma ORM queries.

Team Capstone Project & Deployment

Weeks 14–16

Collaborate in agile squads to architect, test, and deploy a production web application to a cloud server.
